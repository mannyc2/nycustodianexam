# Recovered SVG example files

This directory preserves nine exact standalone SVG Library objects. Original filenames are unchanged.

The standalone SVGs were scanned for scripts, event handlers, `foreignObject`, `javascript:` URLs, external HTTP references, data URLs, and CSS imports; none were present.

Derivative PNG previews/contact sheet and the separately generated ZIP archive were materialized, checksummed, inspected, and recorded in the orchestration file ledger, but are excluded from this Git branch to avoid duplicating source assets with render/archive outputs.
