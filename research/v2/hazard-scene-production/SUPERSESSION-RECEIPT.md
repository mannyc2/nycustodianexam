# R2.9 visual-authoring supersession receipt

## Decision

On 2026-08-23 maintainers adopted
`../../../illustration/VISUAL_AUTHORING_POLICY.md` and superseded R2.9's
deterministic-first authoring-route recommendation.

Current production uses Codex-native image generation for isolated tools and
hazard scenes. Publicly released official sample artwork may guide high-level
visual style within the security/originality boundary. Accepted reviewed raster
bytes control; SVG/CAD/Blender sources and image-model regeneration are not
required.

## Retained contracts

This supersession does not discard R2.9's semantic scene manifest,
target/decoy/negative inventory, final-pixel review, human-authored regions,
stable zone order, accessibility, QA failure codes, immutable versions, offline
payload, and answer-leak rules. Those contracts apply to Codex-generated images.

## R2.10 relationship

production-art candidates. This decision intentionally avoids maintaining an
SVG/CAD repair path beside the Codex route.

## Scope

All Tier A/B concepts remain launch scope. The revised pilot measures native
dimensions, production briefs, and batching; it does not decide whether those
concepts launch.
