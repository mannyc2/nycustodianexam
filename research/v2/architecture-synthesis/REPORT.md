## Content compiler

The accepted path is:

```text
authored JSONC
  -> structural decode and migration
  -> duplicate-preserving registry
  -> relational/provenance/review/accessibility/security gates
  -> validated corpus
  -> canonical immutable objects and page inputs
  -> recomputed closure and hashes
  -> release manifest promoted last
```

Invalid, unsupported, conflicting, inaccessible, stale, source-less, or
unreviewed material does not publish. Exact accepted visual bytes participate in
asset identity and review closure.

## Browser, durability, and offline

- Static HTML pages pay no Effect cost; interactive code loads lazily.
- Direct DOM is the smallest first renderer. Renderer-neutral snapshots and
  commands preserve a bounded lit-html exit if named complexity triggers appear.
- One strict native IndexedDB transaction commits the attempt event,
  projections, and session checkpoint. Reveal waits for transaction completion
  or same-ID reconciliation.
- Provider choice remains private. Test the first-party Effect provider against
  the full browser contract and use `idb@8.0.3` if it fails.
- Packs stage/verify outside transactions and activate with a short generation
  flip. BroadcastChannel is advisory only.
- The native service worker owns HTTP bytes; IndexedDB owns logical pack and
  learner truth.

## Visual production

`illustration/VISUAL_AUTHORING_POLICY.md` now controls:

- Codex-native image generation creates isolated tools and hazard scenes;
- publicly released official sample artwork may be supplied to copy its
  high-level monochrome test-art style, never its item content or composition;
- secure, remembered, candidate-recalled, and rights-unreviewed FOIL material is
  prohibited;
- the exact accepted reviewed raster bytes—not a seed, prompt, SVG/CAD model, or
  model rerun—are the visual source of truth; and
- generation remains outside the runtime/build dependency graph.

The visual pilot first measures actual native output dimensions. One full-canvas
image is the default for obscure/confusable tools. A multi-image grid is adopted
only if a measured trial preserves per-tile pixels, decisive features, style,
and review labor. Hazard scenes use an authored semantic and negative-hazard
inventory, with regions/descriptions bound to the accepted final pixels.

All Tier A/B concepts remain launch scope.
