---

# 4. HttpClient decision

## Verdict

**Use Effect Platform `HttpClient` for application-owned networking, but hide it behind a project service.**

Recommended users:

* `ContentPackSource`
* `ContentManifestSource`
* A later `WorkerApiClient`

Not recommended users:

* HTML, CSS, image, font, or module loading
* Browser navigation
* Native form submission
* Service Worker fetch-event dispatch
