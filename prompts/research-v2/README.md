## Historical launch semantics

The `{{POST_CURATION_SOURCE_SHA}}` token was intended as a launch-time variable
supplied by the original task. The archived contract required connected GitHub,
an exact immutable base, an early branch/draft PR, and incremental publication
without force. Exact receipts—not this synopsis—control what each run actually
executed. R2.6 was later recovered from a checked current-main base because its
original placeholder was never populated; normalization does not claim
retroactive compliance.

For new research, start from current `AGENTS.md`, maintained authority,
`research/README.md`, and a newly supplied immutable GitHub SHA. Define a fresh
branch and minimal durable evidence set; do not recreate the deleted lane trees
or receipt/raw-results structure merely because these prompts once requested
them.
