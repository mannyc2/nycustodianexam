# LANDSCAPE.md

Canonical competitive, product, accessibility, illustration, learning-science, and SEO landscape for the NYS Entry-Level Custodians & Janitors study-site project.

This document is part of the provenance-tracked research corpus. It should be read together with `FACTBASE.md`, `SCOPE.md`, `TAXONOMY.md`, and `OPEN.md`.

## Project positioning
- Free, independent, unofficial study site for the NYS Entry-Level Custodians and Janitors written-test series.
- Primary operational audience: Nassau County / North Bellmore; extensible to jurisdictions demonstrably using the same three-subject plan.
- Product differentiation: original monochrome tool illustrations; original hazard scenes; per-fact citations; dated announcement profiles; local-first/offline PWA; Spanish support; print rehearsal; corrections/source transparency.
- The site's provenance and restraint are strategic assets. It must not imitate the commercial/SEO-junk pattern of promising “actual questions,” “verified answers,” guaranteed passing, fabricated urgency, or unverifiable review counts.

## Competitor / resource landscape
### Official
Official NYS DCS and local civil-service pages generally provide controlling facts, announcements, and small sample/test-guide corpora, but not an end-to-end study product with a substantial original practice bank, visual tool atlas, hazard-scene practice, spaced review, print rehearsal, and per-answer sourcing.

### Commercial
Passbooks and job-test-prep vendors occupy generic civil-service preparation SERPs. Product-market weaknesses include generic breadth, unclear provenance against the exact NYS series, limited free access, and little transparent distinction between official scope and vendor-authored material.

### SEO-junk / dump ecosystem
Observed patterns include pages using language such as “verified answers,” “correct answers,” “actual questions,” “latest update,” and “guaranteed pass.” These pages create both a safety/provenance problem and an SEO opportunity: lawfully intercept answer-seeking intent with a transparent page explaining that secure real questions are not offered, then route users to original sourced practice.

### Libraries / public resource pages
Public libraries and municipal resource pages are realistic distribution channels because civil-service test preparation is already within their public-service remit. Nassau Library System, Town of Hempstead, Suffolk libraries, and similar institutions may link to useful free resources when the destination is genuinely substantive and noncommercial.

## Learning/product evidence incorporated
- Retrieval practice should require an answer commitment before reveal.
- Feedback should explain the correct answer and why distractors fail.
- Confusable visual tools benefit from side-by-side distinguishing-feature instruction.
- Tool identification should use multiple angles and mechanically coherent original art.
- Safety/hazard learning should include original scenes and false-positive/miss feedback.
- Practice results must not be represented as official scores or pass predictions when official item counts/weights/conversion are unverified.
- Selectable practice lengths and a two-hour endurance mode are site-designed rehearsal formats, not claims about official item count.

## Accessibility / image strategy
There are two image-description contexts:
1. **Atlas/reference pages:** descriptive alt text and full nonvisual descriptions are appropriate and useful for accessibility and image search discovery.
2. **Scored attempts before commitment:** naming the target tool or hazard in alt text would reveal the answer. Use neutral contextual text during the attempt, then expose the full description after commitment. A first-class nonvisual equivalent should test the same underlying knowledge without pretending it is identical to the visual-recognition task.

Tool drawings are intended to be original monochrome instructional line art: black on white, limited functional hatching, isolated objects where applicable, varying angles, mechanically coherent, expressly not to scale, and not imitating official exam artwork. Hazard scenes use original environments and annotations only after reveal.

## Print-system principles
- 10-question short drill.
- Selectable 45/60/90-question practice sessions.
- Two-hour endurance packet.
- Generic bubble answer sheet, not an official-form copy.
- Separate answer-key packet with correct answer, explanation, distractor rationales, and source citation.
- Black-and-white home-printer optimization; avoid splitting a question from its image.
- Printable rehearsal supports the paper-booklet / separate-answer-sheet transfer skill while avoiding unsupported claims about current administration details where the admission notice controls.

## Spanish / multilingual principles
- Preserve canonical English tool/title terminology while providing professionally reviewed instructional Spanish.
- Do not imply the official exam is bilingual unless the controlling source says so.
- Translate substantive page content, not just navigation chrome.
- Use proper language URLs/hreflang once real translated counterparts exist.

# SEO strategy — 2026-08-18 research update

## Keyword / intent landscape
Priority intent families:
- `custodian exam`, `custodian test` + NY / Nassau / Suffolk / civil service / school / year.
- `civil service custodian exam practice test`, `study guide`, `questions`.
- title variants: janitor, cleaner, school custodian; high-level/head-custodian terms kept in a separate cluster.
- logistics: exam date, results, eligible list, scoring, what to bring, passing score.
- answer-seeking: actual questions, answers, answer key, leaked/verified questions.
- adjacent but separate: NYC Custodian/Custodian Engineer exam-number clusters.
- Spanish: `examen de custodio`, `examen de conserje`, NY/civil-service variants.

Exact public search-volume numbers were not available in the research environment. Google Trends is normalized and Keyword Planner requires authenticated account data, so relative magnitude must be reported directionally rather than fabricated. Search Console should become the site's own demand instrument after launch.

## Seasonality
Demand is expected to be event-driven around filing windows, announcement publication, admission notices, test dates, and results/list events rather than a stable annual cadence. Nassau's historical administrations are irregular, so do not manufacture yearly pages. Trigger profile creation/update from actual official announcements.

## “Actual questions/answers” interception
Create one high-quality indexable explainer for queries seeking real/actual questions. It should:
- state that the site does not host secure, leaked, remembered, or reconstructed items;
- explain the distinction between officially published samples and secure examinations;
- link to the official DCS sample guide;
- offer substantial original practice, tool drawings, and hazard scenes immediately;
- avoid clickbait title language that implies possession of real questions.

This is both user service and an opportunity to displace low-provenance dump pages without adopting their tactics.

## SERP gap conclusions
- Official sources are authoritative but frequently poor at “what does this mean for me?” explanation and study workflow.
- Thin commercial/dump pages are most vulnerable on practice/question intent.
- Strong opportunities exist for tool-image/reference searches, exact Nassau logistics, scoring explainers, and lawful answer-seeking interception.
- FAQ-style concise facts can help normal organic snippets, but this independent site should not expect FAQ rich results.

## Hub-and-spoke architecture
Recommended indexable hierarchy:
- statewide series hub;
- jurisdiction hub only when it passes a unique-value gate;
- immutable exam-number profile pages for individual administrations;
- shared atlas/tool leaves and family/comparison pages;
- shared practice/hazard/print methodology pages;
- high-level series kept separate;
- NYC-adjacent pages only as explicit disambiguation if pursued.

### Jurisdiction publish gate
There is no legitimate SEO “minimum word count.” A county/jurisdiction page should be indexable only when it contains real unique utility such as several of:
- verified controlling announcement/profile facts;
- local eligibility/jurisdiction information;
- local filing/test/status dates;
- local source links;
- local list/results guidance;
- meaningful differences from the statewide hub.

A page whose only difference is a county name or a link to the same shared practice should not be indexable. This avoids doorway-page behavior.

## URL strategy
Prefer stable path URLs over query-string profiles, e.g.:
- `/ny/`
- `/ny/nassau-county/`
- `/ny/nassau-county/custodian/60112026/`
- `/atlas/`
- `/atlas/tool/pipe-wrench/`
- `/atlas/family/wrenches/`
- `/practice/` for landing/setup; individual session/question state should generally not be indexed.

## Expired/past exam profiles
Do not recycle an old exam-number URL for a new administration. Keep the historical page and change its state after the exam (past administration, results pending/list established/etc.). Historical pages retain useful exact-query and provenance value. Link prominently to the newest relevant administration from the jurisdiction hub.

## Internal linking
- Prep hubs → exact logistics/profile pages via “taking this administration?” modules.
- Logistics/profile pages → appropriate statewide study/practice pages.
- Tool atlas leaves → family/confusable-pair pages and practice actions.
- Answer-seeking explainer → official samples + legitimate practice.
- Historical profiles → current jurisdiction hub/new administration rather than being orphaned.

## Pseudonymous / anonymous E-E-A-T strategy
A real-name credentialed author is not required to build trust here, and one must not be fabricated. Prioritize:
1. direct per-fact official citations;
2. stable project/pseudonymous organizational identity;
3. methodology/source-hierarchy page;
4. corrections policy and visible correction history;
5. “last verified” dates on time-sensitive facts;
6. independent/unofficial disclaimer;
7. original-content/security policy;
8. explicit unknowns instead of guesses;
9. outbound links to controlling .gov/public sources.

Normal useful outbound links to official sources should generally be followed. Blanket `nofollow` on editorial citations would be counterproductive; reserve sponsored/ugc/no-follow attributes for their actual purposes.

## PWA / rendering
The app may be offline-first, but acquisition pages must expose substantive crawlable initial HTML. Use static generation, SSR, or hybrid rendering for hubs, profiles, atlas leaves, methodology, FAQ, sources and other search landing pages. Hydrate interactive study state client-side. Do not require user interaction for primary indexable content to appear.

Question/session URLs are product state, not acquisition inventory; keep them out of indexing where appropriate.

## Core Web Vitals
Optimize mobile-first and low-bandwidth use. Current good field thresholds at p75:
- LCP ≤ 2.5 s
- INP ≤ 200 ms
- CLS ≤ 0.1

Prefer real field data once available rather than optimizing only to synthetic Lighthouse scores.

## Image SEO
Use the atlas as the image-search acquisition surface:
- descriptive alt text appropriate to the tool and page purpose;
- surrounding explanatory text;
- descriptive page titles/headings;
- crawlable image URLs;
- image sitemap where useful;
- original SVGs are indexable; consider raster derivatives/share images as needed for broader preview compatibility without replacing SVG accessibility/print advantages.

Scored quiz pages retain neutral pre-answer descriptions because accessibility cannot reveal the target answer. They do not need to compete as image-search landing pages.

## Structured data — current status
- `BreadcrumbList`: appropriate on indexable hierarchy pages.
- `Organization`: reasonable for site/project identity where accurate.
- `FAQPage`: markup may be semantically valid, but Google FAQ rich results are generally restricted to authoritative government/health sites; do not build an SEO plan around it.
- `HowTo`: Google rich-result support is deprecated; do not implement merely for search appearance.
- `QAPage`: inappropriate for site-authored FAQ/practice pages where users cannot submit competing answers.
- `Quiz`: Google's supported Education Q&A feature is narrowly aimed at flashcard/education question-answer content, not a generic practice-test rich-result mechanism.
- **Practice Problem structured-data support was removed from Google Search documentation/features in January 2026. Do not plan around it.**

## Multilingual SEO
Use dedicated crawlable Spanish URLs for genuine translations and bidirectional `hreflang` (including self-references) once counterparts are complete. Either translated or stable same-meaning slugs can work; prioritize URL stability and editorial maintainability. Avoid machine-translated thin pages published at scale without review.

## Measurement
Search Console should be segmented into practical query/page clusters:
- prep/practice;
- logistics/results/list/scoring;
- answer-seeking;
- atlas/image-search;
- Nassau;
- other NY jurisdictions;
- Spanish;
- high-level/head-custodian;
- NYC adjacent/disambiguation.

Record SERP/rank snapshots around real announcement events rather than running expensive daily tracking across tiny-volume queries. Suggested checkpoints: announcement publication, filing midpoint/close, T-14, T-7, T-1, post-exam, results/list events.

## Link/distribution opportunities
Priority outreach after the site is substantively useful:
1. public library civil-service/test-prep resource pages — statewide/Nassau hub or free practice hub;
2. Town/municipal civil-service study-resource pages — jurisdiction explainer or statewide hub;
3. school facilities associations / relevant union education contacts — cited free prep/tool atlas;
4. district/BOCES adult-ed or classified-employment resource pages — local jurisdiction profile;
5. county candidate-resource pages where external resources are editorially appropriate;
6. r/Custodians / county subreddits — participate genuinely, link only when directly answering a user's need; never mass-post/spam.

Honest pitch: a free, independent, cited resource with original practice and illustrations for an exam patrons/candidates already ask about.

## 90-day SEO sequencing
### Before / around exam event
- ship statewide hub, Nassau hub, current Nassau profiles, atlas foundation, lawful actual-questions explainer, sources/methodology/corrections pages;
- ensure SSG/SSR and mobile CWV basics;
- use descriptive atlas image metadata and keep scored sessions nonindexable/neutral;
- verify current Nassau facts close to the exam date rather than rewriting titles for freshness theater.

### Immediately post-exam
- flip current profiles to past-administration/results-pending state without deleting history;
- publish results/list explainers;
- do not ingest recalled secure content;
- begin library outreach once the site has enough substantive practice to merit a link.

### Following 1–3 months
- expand atlas/family/procedure/safety leaves only from QA-approved sourced content;
- launch reviewed Spanish surfaces incrementally;
- expand to other counties only when the same-plan and unique-value gates are satisfied;
- prune/noindex thin jurisdiction pages instead of padding them;
- use Search Console impressions to discover actual vocabulary and prioritize pages.

## SEO-junk tactics explicitly prohibited
- fake “actual questions” bait;
- copied/reconstructed secure exam content;
- keyword-stuffed city/county doorway pages;
- auto-generated year pages without an announcement;
- fabricated ratings/review counts/testimonials;
- false urgency / “latest” claims without dated verification;
- unsupported guaranteed-pass, official-score, or official-length claims;
- mass AI translation without substantive review;
- link schemes or subreddit/community spam.

## Key current SEO sources
- Google Search Central spam policies / doorway abuse
- Google Search Central helpful, reliable, people-first content guidance
- Google Search Central JavaScript/PWA indexing guidance
- Google Search Central mobile-first indexing
- Google Search Central image SEO
- Google Search Central structured-data gallery / Education Q&A / QAPage
- Google Search documentation update log (Practice Problem removal, Jan. 2026)
- Google Search FAQ/HowTo change announcement
- Google multilingual/multiregional guidance
- Google link crawling/outbound-link guidance
- Google Core Web Vitals guidance and web.dev thresholds

## Delta from prior project assumptions
- No arbitrary jurisdiction-page word threshold should be used.
- Doorway prevention needs to be an explicit publishing rule.
- Historical exam-number URLs should remain stable.
- Acquisition pages need SSG/SSR/hybrid initial HTML despite offline-first product architecture.
- Practice Problem rich-result support is gone as of Jan. 2026.
- Quiz schema is not a generic exam schema.
- FAQ/HowTo rich-result expectations should be low/none for this project.
- Pseudonymous authorship is compatible with a strong evidence/methodology identity.
- Atlas-versus-quiz image-description split is both accessibility-correct and SEO-useful.

No direct contradiction was found between these SEO findings and the previously established LANDSCAPE assumptions; the major correction was to an earlier SEO recommendation that still contemplated Practice Problem structured data.
